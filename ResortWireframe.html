Component Annotations — Mobile & Tablet
①
Navigation Logo left, "← Return to Browse" button right on both breakpoints. No hamburger needed — only one button.
②
Hero — Reduced Height Shorter than desktop. Still shows faded resorts.image_url background. Resort name + country centred.
③
Cards — Stacked Vertically Both frosted cards stack full-width below the hero in document flow. Overview first, Details second.
④
Data Source Colours Yellow = resorts table   Green = resort_details table. All values via PHP htmlspecialchars / number_format.
⑤
Feature Badges Boolean fields (night_skiing, ski_school, terrain_park) from resort_details. Red dot = false, green dot = true. Wrap naturally on narrow screens.
⑥
PHP Defensive Logic If $resort_id ≤ 0 or resort not found → redirect to browse.php. If $details is null → fallback text shown in details card instead of data.
